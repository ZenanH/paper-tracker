# Crossref 抓取可靠性调查

2026-10-29：本地历史任务中32条非空抓取错误均为 crossref_http_404（包含重复轮次），集中在电子刊号，并非限流证据。

原因：目录有效的 ISSN 不保证存在 Crossref /journals/{issn}/works 端点。旧实现把单个电子刊号404当作整刊终止，即使纸质刊号已完成。

修复：期刊端点首页404时，持久化切换至 /works?filter=issn:{同一刊号},...，继续相同窗口、分页、字段投影与 DOI 去重。空200可完成该分片；替代路径失败仍报告失败，不能跳过伪装完成。翻页404先重置过期cursor，再判断首页端点。

实测1879-2138，全局精确ISSN过滤2026-10-01至28返回200、total-results=0；这仅证明该路径可用，不代表出版社已完整登记所有论文。

保持并发1、请求间隔至少1秒、40秒超时、有限指数退避和Retry-After、日期分片与持久检查点。RSS不替代历史补抓，不按名称模糊匹配其他期刊。

待验收：修复后33刊完整轮次；实际网络异常与429场景。不能声称所有期刊100%收齐。
